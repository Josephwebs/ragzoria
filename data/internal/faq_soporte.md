# Preguntas Frecuentes de Soporte TI

## Acceso a aplicaciones internas

Para solicitar acceso a una aplicacion interna se debe crear un ticket con categoria "Accesos", indicar aplicacion, perfil requerido, motivo y aprobador. El plazo estandar es de 2 dias habiles despues de aprobacion.

## SAP

Los problemas de acceso a SAP pueden deberse a rol no asignado, usuario bloqueado o falta de aprobacion. La Mesa de Ayuda debe revisar el estado del usuario en SAP antes de escalar.

## VPN

Si la VPN no conecta, se debe verificar internet, version del cliente, estado de MFA y fecha del sistema. Si el error afecta a varios usuarios, se revisa primero el gateway corporativo.

## Servicios cloud

Las solicitudes relacionadas con Azure, Microsoft 365 o almacenamiento cloud deben incluir servicio afectado, usuario, mensaje de error, hora aproximada y criticidad operacional.
